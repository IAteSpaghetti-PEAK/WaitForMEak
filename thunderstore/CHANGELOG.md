# Changelog

## 0.1.0

First release.

- Players joining a run that's already underway are held as ghosts and then revived next to the
  lowest living scout, once that scout is standing somewhere solid.
- If the lowest scout stays unstandable too long, the joiner is dropped on the lowest scout who
  is standing somewhere instead.
- Ascent 7/8 starting Curse is applied to joiners; optional revival Curse on top (off by default).
- Optional pack on arrival: always a fanny pack, or only a backpack/fanny pack that was left
  behind somewhere in the run (off by default).
- Host only — joining players don't need the mod.
