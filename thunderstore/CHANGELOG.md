# Changelog

## 0.1.2

The mod now stands down in the Void once the soul is freed, since the game deliberately keeps
joiners out at that point and putting them back on their feet would override the ending.

The spectate line now says LOWEST SCOUT rather than LOWEST PLAYER.

Readme now says to uninstall Reconnect Catchup if you have it, because both mods grab a joiner the
moment they arrive and end up fighting over them.
